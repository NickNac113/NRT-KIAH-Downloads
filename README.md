# NRT KIAH Downloads

Public release downloads and the SkunkCrafts update depot for **NRT KIAH Campus**, X-Plane 12.

**[Download and install](https://nicknac113.github.io/NRT-KIAH-Downloads/)** · **[Version archives](https://github.com/NickNac113/NRT-KIAH-Downloads/releases)**

The update feed is `https://nicknac113.github.io/NRT-KIAH-Downloads/depot`. Use the ZIP for first installation; its configuration connects SkunkCrafts automatically. Keep the folder name `NRT_KIAH_Campus` for subsequent updates.

MisterX Library, OpenSAM and openSAM_Library are separate dependencies. Keep your working installations or obtain them from their developers. The scenery updater does not manage shared libraries/plugins or scenery selection.

This repository contains only released files, their notices/editable scenery source and the public download workflow. Development history is maintained privately. Generated releases are immutable: changing scenery requires a new version number.
