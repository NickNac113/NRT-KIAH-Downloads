NRT KIAH - installation and content channels

Member release: 0.29.1 / R29.1. Main and Airport Only share this version.
In-simulator visual and operational checks remain separate from offline validation.

One folder, one release version, two choices:
  Main: airport refinements plus the fictional NRT campus/ramp.
  Airport Only: the same airport refinements without the fictional NRT campus.
These are content variants, not different beta/stable quality levels.

FIRST INSTALL
Close X-Plane. Extract the first-install ZIP into the X-Plane 12 root.
The resulting folder must be Custom Scenery/NRT_KIAH_Campus, with the updater
configuration and Earth nav data directly inside it. Avoid double nesting.
Main is the initial choice and preserves the existing NRT member experience.

Disable other KIAH/NRT test versions in scenery_packs.ini; retain them for
rollback. Put this airport ABOVE AEP, AEP Overlays, other KIAH scenery and
Global Airports. Higher entries take priority. See SCENERY_ORDER.txt for
priority instructions and an optional manual Windows order helper.
The entry must end with a slash:
SCENERY_PACK Custom Scenery/NRT_KIAH_Campus/

CHANNEL SWITCHING
Use the current standalone SkunkCrafts Updater, at least version 4.2.3.
With X-Plane closed, check NRT KIAH Campus to discover its public channels.
Select Main or Airport Only in the channel selector. Run a full check and
repair/update even when the version number is unchanged. Wait for completion
and an up-to-date result before starting X-Plane. To switch back, select the
other channel and repeat. Do not install a second copy of the scenery.
The updater replaces shared airport files and removes managed files belonging
only to the other variant. Folder name and scenery order stay the same.
Do not hand-edit the module URL or delete SkunkCrafts' own state folder.

DEPENDENCIES AND PRESERVATION
Keep MisterX Library, OpenSAM and openSAM_Library installed separately for
Main. Airport Only uses native X-Plane airport assets; its default animated
airport jetways do not require the fictional campus's OpenSAM door controls.
AEP is not required by either variant. This update does not install/remove
plugins, libraries, aircraft, preferences or scenery_packs.ini.
Personal files outside managed paths survive switching. Keep custom edits
outside managed paths, or use the updater's user ignore file deliberately.
Fully restart X-Plane after any scenery update.

NATIVE JETWAY CONTROL
Terminal B already uses native X-Plane 12 animated jetways. To let X-Plane
control them, open OpenSAM > Settings, turn off Manage XP12 Jetways, and fully
restart X-Plane. This is a global preference. Keep OpenSAM installed for the
NRT hangar doors. Use Toggle jetway attachment in X-Plane's Ground Handling
window. See JETWAYS.txt for the camera-distance diagnosis and docking checks.
The updater does not change plugin preferences.

concrete surfaces, and adds two bounded overlay exclusions. The current
continuous apron, taxi guidance, starts, jetways and service routes remain.

run a full SkunkCrafts check/update to receive the scenery repair itself.

passenger window artwork, night glazing and roof detail. No AEP is required.

R28.1 corrects route-node ordering that caused scenery loading warnings.
Taxi/service route geometry and all parking/jetway positions are unchanged.
Both variants include R28 Terminal B North native terminal materials and

night appearance still require simulator checks. Read the historical R27/R28
review notes and the current release status; offline checks are not in-game
acceptance. VARIANT.txt identifies the installed content choice.
