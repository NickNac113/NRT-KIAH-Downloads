# Install NRT KIAH Campus

Download the latest scenery ZIP from [NRT KIAH Downloads](https://nicknac113.github.io/NRT-KIAH-Downloads/).

1. Close X-Plane. Extract the ZIP into your X-Plane 12 folder. The result must be `Custom Scenery/NRT_KIAH_Campus/skunkcrafts_updater.cfg`, with `Earth nav data` beside it. Avoid a second nested `Custom Scenery` folder.
2. Keep **MisterX Library**, **OpenSAM**, and **openSAM_Library** installed. These are separate dependencies and are not included in this download. Use their developer distributions; keep the copies already working on your PC.
3. Back up `Custom Scenery/scenery_packs.ini`. Disable previous NRT/KIAH test scenery entries (R20, R21, R22, R23, etc.) so only this KIAH package is active. Keep their folders for rollback. Put `SCENERY_PACK Custom Scenery/NRT_KIAH_Campus/` above other KIAH airport packages and Global Airports, with the libraries below the airport. Keep the final slash.
4. Run the current [SkunkCrafts standalone updater](https://updater.skunkcrafts.com/) against this X-Plane folder. It should find **NRT KIAH Campus**. Check and update when offered, with X-Plane closed.
5. Fully exit and restart X-Plane after updating, then load KIAH. Check hangar doors, jetways, canopy clearance, pavement and night lighting on your PC. If controls or jetways are missing, run `Check OpenSAM.cmd` in the scenery folder and enter the X-Plane root. It reads the scenery configuration and Log.txt without changing them.

The current member release is **0.23.0 (R23)**. It adds a cohesive FBO/private terminal exterior, a side-entry canopy stand facing south toward the passenger-door alignment, one NRT10 helipad, cleaned-up fencing/paint and a native crew-car route to the arrival curb. BBJ2 operations require tow-in/tow-out; depart the canopy by backing out north. There is no through exit across the south fence.

Hangars are configured open by default. All eight door controls and 119 native airport jetway records are preserved. R23 has offline geometry/export checks; live door operation, jetways, marshalling, vehicle motion, wet surfaces and lighting still require simulator testing. Missing OpenSAM controls/jetways have not been confirmed fixed. See `README_R23.txt` for test notes.

Future updates replace files inside the same `NRT_KIAH_Campus` folder. They do not manage libraries, plugins, aircraft, preferences, or `scenery_packs.ini`. Keep personal custom files outside managed paths or use SkunkCrafts' ignore file. Old versioned scenery folders are not removed automatically.

For rollback, close X-Plane, disable the stable folder and re-enable your previous versioned package. Download links are public; a GitHub account is not required.
